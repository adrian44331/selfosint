# selfosint

About this project
This project is a small, browser‑based OSINT tool that I built for personal use, experimentation, and learning.
It is not a professional product, not intended for commercial purposes, and not designed to replace any established OSINT platforms.

Intended use
Personal research

Learning and experimentation

Testing how different platforms respond to public profile checks

Exploring basic pattern extraction from public webpages

Not intended for
Commercial or enterprise use

Security auditing

Penetration testing

Circumventing protections, restrictions, or access controls

Any activity that violates the terms of service of other platforms
